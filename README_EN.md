## 🚀 Project evolution

The learning journey evolved from visual communication fundamentals toward increasingly interactive digital products:

**Fundamentals → Composition → Identity → Web Page → Application → Game → Portfolio**

### 1. Web Page — B12 Editor

The first practical digital-production stage. Students apply composition, hierarchy, typography, color, visual identity, content organization, and publishing while creating web pages.

### 2. Web Page and App — Base44

The second expansion stage. Creation moves beyond visual presentation into **interaction, flows, components, prototyping, and digital experiences**. The platform is used as a means to turn ideas and briefs into pages and applications.

### 3. Game Creation — InstaPlay

The third expansion stage introduces **AI-assisted game creation**, allowing students to work with concepts, mechanics, interaction, narrative, and user experience.

The progression can be summarized as:

> **Page → Application → Game**  
> **Visual → Interaction → Experience**
