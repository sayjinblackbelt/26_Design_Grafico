# 🎨 Graphic Design — Educational Repository

A repository dedicated exclusively to the educational journey of **Graphic Design**, bringing together fundamentals, methodology, activities, projects, visual examples, and technical documentation.

> **Digital Media has its own proposal and repository.** The areas may complement each other, but this project specifically documents visual language, composition, color, identity, and graphic production.

## 🎯 Purpose

Develop the ability to **think, plan, create, evaluate, and improve visual solutions**.

**Fundamentals → Application → Project → Review → Improvement → Portfolio**

## 🧠 Educational approach

- Project-Based Learning (PBL)
- Educational Sprints inspired by Scrum
- Guiding questions and reflection
- Organization of thought
- Autonomy and responsibility
- Collaborative work
- Hands-on learning and continuous improvement

## 📚 Contents

Graphic design fundamentals, color theory, typography, composition, visual communication, Google Slides, image editing, storytelling, Canva, visual identity, brand kits, portfolio development, and project workflows.
