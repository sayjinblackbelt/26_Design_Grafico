## Actividad — Creación de páginas web con IA

Una actividad práctica sigue el flujo:

**ChatGPT → plataforma de creación con IA → publicación → portafolio**

Los educandos utilizan ChatGPT para desarrollar ideas, responder preguntas guiadas, estructurar el briefing y crear o revisar prompts. Posteriormente utilizan herramientas como **B12** y **Base44** para transformar las propuestas en páginas web o prototipos publicados.

El objetivo es desarrollar la capacidad de **planificar, dirigir, revisar y mejorar una solución visual**, y no simplemente aceptar el primer resultado generado por IA.

### Etapas

1. Definición de la idea.
2. Identificación del público y objetivo.
3. Elección del estilo visual.
4. Definición de colores, imágenes y contenido.
5. Construcción del briefing.
6. Creación y revisión del prompt en ChatGPT.
7. Ejecución en la plataforma.
8. Personalización del resultado.
9. Publicación.
10. Registro en el portafolio.

### Criterios mínimos

- Proyecto individualizado.
- Tema y público definidos por el educando.
- Uso consciente de ChatGPT.
- Prompt estructurado y revisado.
- Página o prototipo personalizado.
- Identidad visual coherente.
- Proyecto publicado.
- Enlace registrado para el portafolio.
