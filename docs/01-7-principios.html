7 Princípios do Design Gráfico.

Aprenda a observar uma composição, identificar os princípios e recriar uma solução própria.

O QUE VOCÊ VAI APRENDER

Conceitos principais

Contraste, alinhamento, proximidade, repetição, hierarquia, espaço em branco e equilíbrio.

1. Entender

  • Observe exemplos e referências.
  • Identifique o objetivo.
  • Organize as informações.

2. Fazer

  • Escolha uma direção.
  • Produza uma primeira versão.
  • Teste e compare.

3. Melhorar

  • Encontre um problema.
  • Faça uma melhoria específica.
  • Teste novamente.

4. Entregar

  • Apresente o resultado.
  • Explique suas decisões.
  • Registre a aprendizagem.
ATIVIDADE

Agora é sua vez

Observe um exemplo → identifique o princípio → recrie no Canva → compare → melhore.

MINHA ANÁLISE

Qual princípio consigo identificar?
Onde esse princípio aparece na composição?
O que mudaria se esse princípio não fosse utilizado?
Como posso recriar essa solução com minhas próprias escolhas?
Que melhoria fiz depois de comparar as versões?
💡 Regra de autoria: use referências para aprender. A solução final deve ser construída a partir das suas próprias decisões.
CHECKPOINT

Antes de entregar

Use estas perguntas para revisar seu trabalho.

☐ Identifiquei.Consigo apontar pelo menos três princípios e explicar onde aparecem.
☐ Recriei.Produzi uma versão própria a partir da referência.
☐ Comparei.Encontrei uma diferença entre as versões.
☐ Melhorei.Fiz uma melhoria baseada nessa comparação.
