Conceitos principais

Conceito, posicionamento, público, palavras-chave, identidade visual, consistência e autoria.

1. Conceito

  • Defina o que a marca representa.
  • Identifique público e personalidade.
  • Organize palavras-chave.

2. Identidade

  • Conecte logo, cores e tipografia.
  • Construa uma linguagem visual consistente.

3. Aplicação

  • Leve a identidade para uma peça.
  • Verifique consistência entre aplicações.

4. Autoria

  • Explique as decisões.
  • Registre referências e alternativas.
  • Apresente a identidade com clareza.
ATIVIDADE

Agora é sua vez

Conheça a marca → defina conceito → projete identidade → aplique → revise → documente.

MINHA IDENTIDADE

Qual é a marca e quem é seu público?
O que a marca deve representar ou comunicar?

Como conceito, cores, tipografia e logo se conectam?

💡 Regra de autoria: use referências para aprender. A solução final deve ser construída a partir das suas próprias decisões.
