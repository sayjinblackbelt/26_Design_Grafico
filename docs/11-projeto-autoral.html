Agora é seu.

Integre os conhecimentos do curso em um projeto próprio. Você define o problema, toma as decisões, escolhe as ferramentas, testa e apresenta.

PROJETO

Você escolhe o que criar.

Possibilidades

  • Identidade visual.
  • Site ou página digital.
  • Aplicação.
  • Jogo.

Integração

  • Princípios de design.
  • Tipografia e cores.
  • Ferramentas digitais.
  • IA como apoio responsável.

REFLEXÃO

O projeto mostra o que você aprendeu.

Não apresente somente o resultado. Mostre o caminho: problema → decisões → produção → teste → melhoria → resultado → aprendizagem.
