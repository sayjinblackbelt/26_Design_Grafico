# 🧩 Modelos — Kit de Marca Autoral PMT

Modelos de referência para execução do Projeto 01.

## Como usar
**Observar → Analisar → Reproduzir → Modificar → Criar**

Os exemplos servem para compreender o conceito. A versão final deve ser autoral.

## 1. Contraste
Exemplo: título grande + texto pequeno + diferença forte de claro/escuro.
Modelo: crie uma composição em que exista uma informação claramente dominante.

## 2. Alinhamento
Exemplo: título, imagem e informações seguindo a mesma linha de referência.
Modelo: escolha um eixo e organize todos os elementos a partir dele.

## 3. Proximidade
Exemplo: título, imagem e legenda agrupados; elementos sem relação mais afastados.
Modelo: organize informações relacionadas em grupos visuais.

## 4. Repetição
Exemplo: repetição de uma forma e de uma cor para criar unidade.
Modelo: escolha um elemento e utilize-o repetidamente na composição.

## 5. Hierarquia
Exemplo: título > subtítulo > informação > detalhe.
Modelo: crie uma ordem de leitura perceptível.

## 6. Espaço em branco
Exemplo: mesma peça antes/depois, reduzindo excesso de elementos.
Modelo: preserve áreas vazias para melhorar leitura e destaque.

## 7. Equilíbrio
Exemplo: uma composição simétrica e outra assimétrica visualmente equilibradas.
Modelo: distribua os elementos de modo intencional.

## 8. Tipografia
Exemplo:
- Título — fonte de destaque, maior tamanho e peso;
- Subtítulo — tamanho intermediário;
- Texto — fonte legível;
- Destaque — uso pontual.

Modelo: 3–4 fontes, cada uma com função definida.

## 9. Paleta de cores
Exemplo: 6 cores organizadas por função:
**principal, secundária, destaque, fundo, texto, apoio**.

Modelo: 5–7 cores + códigos HEX + função.

## 10. Conceito da marca
Exemplo:
**PULSO**
Energia, ritmo, movimento e linguagem urbana.

Modelo:
- Nome;
- O que representa;
- Para quem;
- 3–5 palavras-chave.

## 11. Esboços
Exemplo: 3 ideias desenhadas → comparação → escolha.
Modelo: produzir no mínimo 3 alternativas antes da versão digital.

## 12. Logo manual
Exemplo: esboço → refinamento → versão digital.
Modelo: registrar o processo e a versão final.

## 13. Logo com IA
Exemplo: conceito → prompt → resultado → análise.
Modelo: guardar prompt, resultado e decisões de refinamento.

## 14. Comparação manual × IA
Comparar:
- interpretação da ideia;
- controle;
- resultado;
- coerência;
- alterações necessárias.

## 15. Aplicações
Exemplos: cartaz, post, camiseta, embalagem, celular ou caderno.
Modelo: pelo menos 2 aplicações.

## 16. Mockups
**Mockup 01:** produzido com recursos do Canva.
**Mockup 02:** produzido com apoio de IA.
Comparar controle, composição, coerência e qualidade.

## 17. Apresentação
Modelo-base de 15 slides:
1. Capa
2. Contraste
3. Alinhamento
4. Proximidade
5. Repetição
6. Hierarquia
7. Espaço em branco
8. Equilíbrio
9. Tipografia
10. Paleta
11. Conceito
12. Esboços + logo
13. Manual × IA
14. Aplicações + mockups
15. Reflexão

## 18. Regra pedagógica
O modelo ensina o caminho; não substitui a criação do educando.
