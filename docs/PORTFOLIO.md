# 🎨 Portfólio — PMT Design Gráfico 2026

> Registro técnico de **um único curso de Design Gráfico**, organizado em Turma 1, Turma 2 e Turma 3.

## Percurso

**Observar → Refletir → Projetar → Produzir → Avaliar → Apresentar**

**Fundamentos → Esboços → Moodboard → Planejamento → Criação → Produção digital → Teste → Revisão → Portfólio**

As plataformas **B12 Editor → Base44 → InstaPlay** são meios de produção dentro do curso, não cursos separados.

## Regra de publicação

A página pública pode apresentar, quando necessário para identificação do trabalho, somente **primeiro nome + turma + projeto + plataforma + data + link**. Não publicar sobrenomes, avaliações, frequência, reflexões individuais, fotos, credenciais, senhas, tokens ou registros do processo pedagógico.

> **Princípio:** Publicar o produto, proteger o processo.

Os registros técnicos utilizam identificadores como `T1-XX`, `T2-XX` e `T3-XX`. Links publicados devem ser preservados nas atualizações.
