# Regra de referência

Quando uma etapa do percurso não possuir arquivo de referência ou modelo adequado, deve ser criado um **modelo mínimo reutilizável** antes de considerar a etapa documentalmente concluída.

O modelo deve:
- ser coerente com a etapa;
- permitir preenchimento posterior;
- não inventar conteúdo;
- preservar a privacidade;
- servir como referência para futuros projetos.

Essa regra vale para as próximas etapas e para futuras revisões deste repositório.
