# Regra de Auditoria — Portfólio

## Regra permanente

Em toda revisão futura deste repositório:

1. Identificar a etapa atual antes de qualquer alteração.
2. Validar arquivos, registros, links e publicação.
3. Se uma etapa não possuir arquivo de referência ou modelo adequado, criar um modelo mínimo reutilizável.
4. Não inventar conteúdo para preencher modelos.
5. Não alterar arquivos existentes sem necessidade.
6. Preservar identificadores anônimos e sanitização de dados.
7. Após qualquer alteração, testar o workflow do GitHub Pages.
8. Se houver falha operacional, repetir a tentativa sem mudanças desnecessárias.
9. Só avançar para a etapa seguinte após validação da etapa atual.
10. Ao final de uma revisão completa, verificar novamente se esta regra continua presente e aplicável.

## Critério de conclusão

Uma etapa pode ser marcada como concluída quando:
- seu conteúdo estiver documentado ou houver modelo de referência;
- os arquivos relevantes estiverem coerentes;
- links e registros estiverem revisados quando tecnicamente verificáveis;
- a publicação estiver funcional;
- não houver dúvida que exija decisão do usuário.

Conteúdo que ainda será produzido pelos educandos pode permanecer como modelo ou campo pendente, sem ser inventado.
